# 可版本化单词内容发布设计

日期：2026-09-23  
关联任务：GitHub Issue #2「发布首个可版本化单词内容」  
状态：已获用户批准，待实施计划

## 1. 目标

建立一套可由非技术内容人员使用的轻量内容生产系统，使一条可复用词汇资产及其教材专属编排能够经过录入、完整预览、人工审核和版本发布后被学生端读取，并支持独立下架与回滚。

系统必须保留历史版本，使已有学习记录能够解释学生当时看到、听到和练习的具体内容。首版使用微信云开发承载管理服务、数据库和对象存储，同时隔离身份、数据和存储适配层，为后续迁移独立腾讯云服务保留边界。

## 2. 范围

本任务包含：

- 轻量网页内容后台；
- 单一管理员身份和服务端授权；
- 可复用词汇资产与教材专属编排的独立存储；
- 不可变内容版本、审核记录、发布记录和审计记录；
- 标准音频与图片的对象存储引用及上传流程；
- 内容预览、审核、发布、独立下架和回滚；
- 学生端只读的已发布内容投影；
- 本地浏览器持久化模式、内存测试仓库和微信云仓库适配边界；
- 批量导入、导出和契约校验命令行工具；
- 一个完整演示词条的端到端发布流程。

本任务不包含：

- 多角色、多级审批、组织和团队协作；
- 开放注册、复杂账号管理或细粒度权限矩阵；
- AI 自动生成内容；
- 多教材批量生产；
- 学习任务编排、复习算法、发音评测执行或学习记录功能；
- 正式支付、权益和商业化流程；
- 直接迁移到独立腾讯云。

## 3. 核心原则

### 3.1 管理入口与数据库隔离

网页后台和命令行工具只能通过 `ContentManagementService` 操作内容，不得直接修改数据库集合。微信云开发控制台仅用于开发排错，不作为正常发布入口。

### 3.2 学生读取与管理写入隔离

学生端继续通过 `ContentService` 读取内容。该服务只返回已人工审核、已发布且未下架的投影，不暴露草稿、审核备注、管理员身份或内部审计信息。

### 3.3 版本不可变

已经建立的内容版本不允许原地修改。任何修订都创建新版本；下架只关闭当前发布指针；回滚只将当前指针切换到一个历史版本。历史版本和学习记录引用不被删除。

### 3.4 人工审核是发布硬门槛

保存草稿、批量导入和预览都不能自动形成审核通过状态。发布命令必须在服务端重新验证人工审核记录、版本一致性和素材完整性。

## 4. 系统架构

### 4.1 网页内容后台

在 `admin/` 建立 React + TypeScript 单页应用，面向内容人员提供录入、预览、审核和版本管理界面。后台依赖内容管理客户端接口，不直接依赖微信云数据库或对象存储 SDK 的业务细节。

后台包含五个页面：

1. 登录页；
2. 内容列表与筛选；
3. 词汇资产和教材编排编辑页；
4. 完整学生内容预览页；
5. 版本历史、审计、下架和回滚页。

### 4.2 内容管理服务

`ContentManagementService` 提供面向业务的命令：

- 创建或更新草稿；
- 建立教材编排；
- 提交审核；
- 审核通过或退回；
- 生成完整预览；
- 发布新版本；
- 下架当前发布；
- 回滚历史发布；
- 查询版本和审计记录；
- 批量导入、导出和校验。

首期服务由微信云函数承载。领域规则和仓库接口保持平台无关，后续可由腾讯云 API 复用。

### 4.3 学生内容服务

现有 `ContentService` 扩展为读取版本化发布投影。页面仍然只依赖该服务与共享契约，不感知管理后台、云数据库集合或存储供应商。

### 4.4 辅助命令行工具

命令行工具用于批量导入、导出、格式校验和发布前检查。导入只创建草稿，不能绕过人工审核直接发布。

## 5. 领域模型

### 5.1 VocabularyAsset

英文词的稳定身份。同一拼写的词汇资产可以被多套教材引用。稳定记录只保存 ID、规范化拼写和创建信息，不保存可变展示内容。

### 5.2 VocabularyAssetVersion

不可变的可复用内容版本，包括：

- 标准拼写；
- 基础中文词义；
- 标准音频媒体引用；
- 谐音故事；
- 联想图片媒体引用；
- 辨义干扰项；
- 纠音候选；
- 适用年龄和内容备注；
- 版本号、创建人和创建时间。

### 5.3 TextbookPlacement

教材、单元和词汇资产之间的稳定关系。它表示某个英文词被某套教材采用，但不保存可变的教材释义和顺序。

### 5.4 TextbookPlacementVersion

不可变的教材专属版本，包括：

- 教材 ID 和单元 ID；
- 教材词义覆盖；
- 单元内词序；
- 适龄表达覆盖；
- 适用状态；
- 版本号、创建人和创建时间。

不同教材引用同一 `VocabularyAsset` 时，各自的教材释义和编排互不影响。

### 5.5 ReviewRecord

记录目标资产版本和教材编排版本、审核人、审核时间、审核结论、检查项和备注。审核结论包括通过与退回；审核记录不可修改，只能新增。

### 5.6 Publication

表示一个原子发布组合，包含资产版本 ID、教材编排版本 ID、发布状态、发布时间、发布人和发布序号。学生端当前指针只指向一个有效 `Publication`。

### 5.7 AuditEvent

记录创建、编辑、提交审核、审核结论、发布、下架和回滚等状态变化，包括操作者、时间、原因和关联版本。审计事件只能追加。

### 5.8 MediaReference

保存对象存储键、媒体类型、格式、大小、内容校验值、版本、授权来源和审核状态。数据库不保存图片或音频二进制内容。

## 6. 状态与工作流

内容工作流为：

`草稿 → 待审核 → 已通过 → 已发布`

1. 内容人员创建词汇资产草稿和至少一个教材编排草稿。
2. 上传或选择标准音频和图片，填写干扰项与纠音候选。
3. 在完整预览中按学生实际顺序检查标准听音、谐音联想、辨义和纠音内容。
4. 提交审核后，当前版本停止编辑；需要修改时退回草稿或创建新草稿版本。
5. 审核人逐项确认词义、标准音、谐音自然度、适龄性、图片授权、干扰项质量和错误发音诱导风险。
6. 审核通过后才允许发布。
7. 发布在服务端事务中同时写入 `Publication` 与学生端当前指针。
8. 下架立即使当前发布停止出现在学生查询中，但保留发布和版本记录。
9. 回滚创建新的审计事件，并将当前指针切换到选定的历史发布。

发布失败时事务整体回滚，旧发布继续提供服务，不允许出现半发布状态。

## 7. 管理后台体验

### 7.1 内容列表

支持按英文词、教材、单元和状态筛选。每行明确显示当前草稿版本、最近审核结果、当前发布版本及是否下架。

### 7.2 编辑页面

页面分为两个稳定区域：

- 可复用词汇资产：拼写、基础词义、音频、谐音故事、图片、干扰项和纠音候选；
- 教材专属编排：教材、单元、词序、教材释义和适龄表达覆盖。

不得把教材专属字段写回共享资产版本。

### 7.3 完整预览

预览使用与学生端相同的发布投影和视图数据，按以下顺序展示：

1. 标准听音；
2. 谐音故事与联想图片；
3. 教材词义和辨义干扰项；
4. 纠音候选。

预览不创建学习记录，也不使内容对学生可见。

### 7.4 高风险操作

发布、下架和回滚都显示目标版本、影响教材和明确结果。下架与回滚要求二次确认并填写原因。

后台采用面向成人的白色表单、清晰字段分组和稳定状态标签，不使用儿童角色、星星奖励或游戏化装饰。

## 8. 身份与授权

身份通过 `AdminAuthProvider` 隔离：

- 本地开发使用明确标识的本地管理员模式；
- 微信云部署使用 CloudBase 自定义身份验证；
- 服务端使用管理员白名单授权；
- 首版不开放注册，只允许一个配置好的管理员身份。

隐藏前端按钮不构成权限控制。所有写入、审核、发布、下架、回滚和上传凭证申请都必须由服务端重新验证身份。

后期迁移腾讯云时替换身份适配器，不改变内容管理命令和领域状态机。

## 9. 素材上传

后台首先向内容管理服务申请上传凭证，服务验证管理员身份、媒体类型和大小限制后，由浏览器直接上传到对象存储。上传完成后，后台提交存储键、校验值和授权信息，服务端验证后创建 `MediaReference`。

只有审核状态有效、格式正确且具备授权记录的媒体引用才能参与发布。删除或替换媒体不得破坏引用该媒体的历史内容版本。

本地模式使用浏览器持久化存储保存内容元数据与本地素材引用，用于无 AppID 情况下演示完整流程。生产模式由对象存储适配器实现上传凭证与媒体校验。

## 10. 学生读取契约

学生端发布词条至少包含：

- 词汇资产 ID；
- 词汇资产版本 ID；
- 教材编排 ID；
- 教材编排版本 ID；
- 发布 ID 和发布时间；
- 英文拼写和教材释义；
- 标准音频引用；
- 谐音故事和图片引用；
- 辨义干扰项；
- 纠音候选。

学生查询按教材 ID 和单元返回当前有效发布。非发布、已下架、审核退回或素材不完整的版本一律不返回。

未来学习记录保存发布 ID、资产版本 ID 和教材编排版本 ID，使系统能够恢复当时使用的内容。历史内容查询是受限的解释接口，不等于重新向学生发布旧内容。

## 11. 数据适配与本地模式

领域服务依赖仓库接口而不是具体数据库：

- 自动化测试使用内存仓库；
- 无 AppID 时，网页后台使用浏览器持久化适配器演示完整工作流；
- 微信云模式使用云函数和云数据库集合；
- 学生内容服务读取独立的已发布投影；
- 命令行工具使用版本化内容包文件。

本地和微信云适配器必须通过相同的契约测试。页面不根据适配器类型改变领域规则。

## 12. 一致性与错误处理

- 草稿更新使用版本号进行乐观并发校验，拒绝覆盖已变化的草稿。
- 发布命令具有请求 ID，重复提交不能产生重复发布记录。
- 发布事务失败时旧版本保持可读。
- 媒体上传成功但内容保存失败时，素材保留为未关联状态，允许重新关联或由后续清理任务处理。
- 管理端显示可操作的中文错误，并保留开发诊断 ID。
- 学生端服务异常时继续使用现有加载、错误和重试状态，不展示内部审核信息。
- 所有跨边界输入都经过运行时校验。

## 13. 测试策略

测试集中在公共接口和关键业务边界：

### 13.1 领域状态机

- 未审核版本不能发布；
- 保存草稿不能自动审核；
- 审核通过后修改内容必须产生新版本；
- 下架和回滚只改变当前指针，不删除历史版本；
- 重复发布请求具有幂等性。

### 13.2 资产与教材隔离

- 同一英文词可以被不同教材引用；
- 修改一套教材的专属释义不会影响其他教材；
- 更新共享资产不会自动替换已发布教材组合。

### 13.3 学生读取安全

- 学生端只读取已审核、已发布且未下架的内容；
- 发布事务失败时继续返回旧版本；
- 历史版本可通过受限解释接口查询。

### 13.4 管理授权与素材

- 未授权请求不能写入、审核、发布、下架、回滚或申请上传凭证；
- 缺少音频、图片、授权信息、干扰项或审核记录时拒绝发布；
- 上传引用的格式、大小和校验值必须通过验证。

### 13.5 适配器契约

内存仓库、浏览器持久化仓库和微信云仓库遵守相同接口和状态规则。云环境无法在自动化测试中真实验证的部分必须记录为部署验收限制。

### 13.6 端到端演示

至少一个完整演示词条能够经历录入、教材关联、素材预览、提交审核、人工通过、发布、学生读取、下架和回滚全过程。

## 14. 验收标准

Issue #2 完成时必须满足：

1. 词汇资产与教材编排独立存储，同一英文词可被不同教材引用并覆盖教材释义；
2. 未通过人工审核的内容无法发布或被学生端读取；
3. 内容人员可在网页后台预览完整词条后发布新版本；
4. 单个发布可独立下架或回滚；
5. 历史版本不会被更新、下架或回滚操作删除；
6. 学习记录所需的版本 ID 可稳定引用历史内容；
7. 命令行批量导入不能绕过人工审核；
8. 一个演示词条完成全生命周期自动化验证；
9. 本地模式无需 AppID 即可演示，真实微信云环境验证等待 AppID；
10. 学生页面和后台页面均不直接访问数据库。

## 15. 迁移边界

迁移独立腾讯云时保留：

- 领域模型和状态机；
- `ContentManagementService` 与 `ContentService` 契约；
- 网页后台页面和管理客户端；
- 学生端发布投影；
- 运行时校验、审计规则和版本引用。

需要替换：

- CloudBase 身份适配器；
- 微信云数据库仓库；
- 微信云存储上传凭证与媒体适配器；
- 云函数传输层和部署配置。

这些替换不得要求内容人员重新录入历史版本，也不得改变学生学习记录中的版本标识。
