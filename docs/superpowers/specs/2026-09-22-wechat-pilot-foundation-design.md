# 微信小程序试点骨架设计

日期：2026-09-22
关联任务：GitHub Issue #1「搭建可部署的微信小程序试点骨架」
状态：已实施并通过自动化验证；真实微信云环境验证等待 AppID

## 1. 目标

为 K12 英语单词速记产品建立可持续演进的正式工程骨架，使用户能够打开微信小程序、访问“学习”和“家长”两个 Tab，并通过统一内容服务加载一套可配置的演示教材数据。

首版使用微信原生云开发降低试点运维成本，同时隔离微信身份、云函数、数据库和文件存储细节，避免学习页面与云开发实现直接耦合，为后续迁移到独立腾讯云服务保留清晰边界。

## 2. 范围

本任务包含：

- 微信原生小程序与 TypeScript 工程骨架；
- “学习”和“家长”双 Tab；
- 本地演示内容适配器与微信云函数内容适配器；
- 可配置的教材、单元和基础词条数据契约；
- 云环境健康检查与内容查询云函数骨架；
- 类型检查、单元测试和构建检查；
- 本地、试点、生产环境的配置与部署说明。

本任务不包含：

- 内容审核、发布、下架和回滚；
- 标准音频、谐音故事、图片和辨义干扰项；
- 微信登录、家庭账号和学生档案；
- 今日航程生成、学习记录和复习调度；
- 发音评测、周报、支付或试点分析。

这些能力由后续 Issues 分别实现。

## 3. 技术选择

### 3.1 客户端

使用微信原生小程序与 TypeScript，不引入 Taro 等跨端框架。首轮产品仅面向微信，原生方案对录音、缓存、云开发和微信开发者工具的兼容性最稳定，也避免额外的框架构建层。

现有 `prototype/` 网页原型继续作为视觉和交互参考，不直接嵌入小程序，也不在本任务中删除或重写。

### 3.2 托管后端

试点阶段使用微信原生云开发，包括云函数、数据库和后续可能使用的云存储。客户端页面不能直接访问云数据库，只能通过业务服务接口调用本地演示适配器或云函数适配器。

后期迁移到独立腾讯云时，主要替换以下边界：

- 云函数运行环境；
- 数据访问实现；
- 文件存储实现；
- 微信身份到内部账号的身份适配。

页面、教材数据契约和核心业务模型不随托管方式变化。

### 3.3 测试工具

使用 TypeScript 严格模式进行静态检查，使用 Vitest 验证共享数据契约、演示数据和服务适配行为。项目提供统一命令执行类型检查、测试和构建检查。

## 4. 项目结构

```text
miniprogram/
  app.*
  pages/
    learn/                 学习 Tab
    parent/                家长 Tab
  services/
    content/               页面使用的统一内容服务
  adapters/
    local/                 无云环境时的演示实现
    cloud/                 微信云函数调用实现
  fixtures/                可配置演示教材数据
  config/                  非敏感运行环境配置

cloudfunctions/
  health-check/            云环境连接检查
  content-service/         按教材标识返回内容

shared/
  contracts/               教材、单元、词条和服务响应契约
  validation/              运行时数据校验

tests/
  contracts/               契约与演示数据测试
  services/                本地和云端适配行为测试
```

具体文件可在实施计划中细化，但模块边界必须保持：页面依赖内容服务接口，内容服务选择适配器，适配器返回共享契约。

## 5. 数据模型

Issue #1 只定义后续内容系统所需的最小可扩展形状。

### 5.1 教材

- 稳定教材标识；
- 出版或版本标识；
- 教材年份；
- 学段；
- 年级；
- 学期；
- 展示名称。

### 5.2 单元

- 稳定单元标识；
- 所属教材标识；
- 单元名称；
- 教材内顺序。

### 5.3 基础词条

- 稳定词条标识；
- 所属单元标识；
- 英文拼写；
- 教材释义；
- 单元内顺序。

数据结构不能将“湘少版”“三年级”或固定单元数量写入页面逻辑。演示数据可以使用首发教材示例，但替换教材标识和数据后，页面流程无需修改。

## 6. 数据流

应用启动时读取非敏感环境配置，并选择内容服务适配器：

```text
学习/家长页面
      ↓
统一内容服务接口
      ↓
本地演示适配器 或 微信云函数适配器
      ↓
共享教材数据契约与运行时校验
```

没有 AppID 或云环境 ID 时使用本地演示适配器。配置真实云环境后，客户端改用云函数适配器。两者必须返回相同的服务响应结构，页面不得根据适配器类型编写业务分支。

学习和家长两个 Tab 读取同一当前教材状态，不各自维护相互独立的教材副本。

## 7. 环境配置

项目区分本地、试点和生产三类环境：

- 本地环境默认使用演示数据；
- 试点环境连接单独的微信云开发环境；
- 生产环境连接正式云开发环境。

仓库只保存环境名称、功能开关和可公开的环境标识示例。密钥、私有凭据和真实生产配置不得提交到 Git。

由于当前尚无小程序 AppID，本任务不会声称完成真实微信云环境部署。获得 AppID 后，需要按照部署文档完成开发者工具导入、云环境创建、云函数上传和真机连接验证。

## 8. 故障处理

- 未配置 AppID 或云环境时，界面明确处于本地演示模式；
- 云函数请求失败时展示可恢复的加载错误和重试入口，不自动伪装为云端成功；
- 服务响应不符合共享契约时拒绝渲染错误数据，并记录明确的开发诊断；
- 单个 Tab 加载失败不能导致应用无法切换到另一个 Tab；
- 环境配置错误应在开发检查或启动阶段尽早暴露。

Issue #1 不实现离线学习队列或学习事件重试；它们属于后续弱网和数据一致性任务。

## 9. 自动化验证

自动化检查至少覆盖：

1. TypeScript 严格类型检查通过；
2. 演示教材、单元和词条符合共享契约；
3. 无效数据会被运行时校验拒绝；
4. 本地适配器可按教材标识返回正确内容；
5. 云端适配器能把云函数成功、失败和无效响应映射为统一结果；
6. 项目生产构建检查通过。

在任务结束前运行单项测试、完整测试套件、类型检查和构建检查。

Issue #1 在满足以下条件后完成：
